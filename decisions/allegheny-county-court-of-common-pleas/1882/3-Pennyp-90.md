# Richardson v. Glockner

## Majority (Per Curiam :)

Per Curiam :
We think there was sufficient in the evidence of Andrew Spath under which the lot in question could be identified from the description contained in the mechanic’s lien. The Courts are in favor of sustaining these claims when the property is so described that those acquainted with the neighborhood are able to identify it.
Judgment affirmed.
